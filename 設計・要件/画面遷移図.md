# 画面遷移図

`画面遷移図-memo.md` をもとにした画面遷移図です。入札は商品詳細画面内で完結し、作品は下書き保存後に作者が出品を選択します。

```mermaid
flowchart TB
    home([ホーム画面])

    subgraph browse[閲覧・入札]
        detail[商品詳細画面<br/>画面内で入札]
        bid_ok[入札結果を表示<br/>最新価格へ更新]
        detail -->|入札額を入力・確定| bid_ok --> detail
    end

    subgraph create[作品作成・出品]
        draw[絵を描く画面]
        draft[(PNGを下書き保存)]
        listing[出品設定画面]
        draw -->|保存| draft
        draft -->|出品する| listing
        listing -->|公開完了| detail
    end

    subgraph member[認証・アカウント]
        login[ログイン／新規登録画面]
        account[アカウント画面<br/>下書き・お気に入り一覧]
        login -->|認証成功| account
        account -->|下書きを編集| draw
        account -->|下書きを出品| listing
        account -->|お気に入り作品を開く| detail
    end

    subgraph support[補助画面]
        notice[通知画面]
        charge[アプリ内チャージ画面]
        payment[支払い画面]
        bonus[ボーナスポイント画面]
        viewer[配信画面（閲覧側）]
        streamer[配信画面（配信側）]
        admin[管理画面／管理者モード]
        charge --> payment
    end

    home -->|作品を選ぶ・タグ検索| detail
    home -->|作品を作る| draw
    home -->|ログイン| login
    home -->|アカウント| account
    home --> notice
    home --> charge
    home --> bonus
    home --> viewer
    home --> streamer

    detail -->|未ログイン時| login
    detail -->|ポイント不足時| charge
    detail --> notice
    detail --> account
    draw -->|未ログイン時| login
    notice --> detail
    account --> notice
    viewer --> notice
    viewer --> login
    viewer --> charge
    streamer --> listing
    streamer --> notice

    classDef primary fill:#1f4b7a,color:#fff,stroke:#163754,stroke-width:2px
    classDef process fill:#e8f1fb,color:#102a43,stroke:#6c9bc9
    classDef state fill:#fff2cc,color:#5c4700,stroke:#d6b656
    class home,detail primary
    class draw,listing,login,account,notice,charge,payment,bonus,viewer,streamer,admin process
    class draft,bid_ok state
```

## 補足

- 商品詳細画面では、作品・オークションのお気に入りを登録または解除できる。
- ホーム画面では、タグを指定して作品を検索できる。
- 入札結果は商品詳細画面内に再表示し、専用の入札画面には遷移しない。
- 描画画面で保存したPNGは下書きとして保持し、作者だけが編集・出品できる。
- 画面番号3の入札画面は廃止済みである。
